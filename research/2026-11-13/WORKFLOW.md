# Batch 14 — publishing and review workflow
1. Inspect main and all earlier batch indexes for novelty. Reserve independent IDs 01–10 to securities finance and 11–20 to global quantitative research.
2. Select falsifiable questions with feasible baselines, genuine economic decisions, independent methodologies and suitable capacity.
3. Verify public official portals, papers and release lags; register any source or license gaps without invented values.
4. Define mathematical objective, decision variables, constraints, source/availability times, data-version contract and realistic execution costs.
5. Generate 14 domain-specific Markdown documents per idea. Mark RUNTIME/AGENT/TOOLING as proposed where no executable code exists.
6. Check count and relative links; report synthetic-only verification. Never assert unrun tests.
7. Commit one dated branch and open exactly one draft PR; verify status/changed files.
8. Notify QuantSmith Slack #quant-model-generator with confirmed PR URL, category top three and caveats.

## Independent human gates
No production deployment until license approval, numerical reproducibility, held-out tests with full costs, risk-limit compliance, CI/quality gates and legal review. Failed ideas are recorded, not silently replaced.
