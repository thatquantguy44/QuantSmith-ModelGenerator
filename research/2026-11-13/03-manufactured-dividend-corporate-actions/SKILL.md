# SKILL — Manufactured-Dividend and Corporate-Action Loan Economics
## Trigger
Use this skill when researching: **Determine whether a permitted loan extension, pre-event return or alternative allocation is economically superior without compromising beneficial-owner legal rights.** in **US and cross-listed global equities**.

## Inputs
Source/version references and license, decision clock, security × beneficial owner program × corporate-action event × decision timestamp, the cost model, allowed actions, and study windows. Minimum fields: Ex/record/pay dates; loan life; fee accrual; event elections; dividend amounts; owner tax flags and permitted return/recall rules..

## Procedure
1. Load SPEC and HANDOFF; state hypothesis and category A · Securities finance.
2. Build source-claim ledger. Do not conflate official data description and available executable market dataset.
3. Check first public availability and carry correction vintages forward, never backward.
4. Create adverse synthetic fixtures and reject invalid market constraints.
5. Fit and run **Renew if lending fee remains positive and return only upon explicit mandatory recall.** on training data with full costs.
6. Define **Rule-checked event economics and constrained loan life-cycle integer optimizer.**, plus optional **Scenario tree for unresolved election announcements and corporate action adjustment ranges.** conditional on simple model advantage.
7. Freeze chronological holdouts and evaluate **net program income, missed payment events, operational exceptions, unauthorized action count.** plus capacity and tail risk.
8. Try to falsify: **Reject if post-cost incremental program income is nonpositive or event-aware policy increases mandatory-payment exceptions.**.
9. Record all negative tests, unverified sources, measured trade-offs and manual approval gate.
10. Return BLOCKED if Tax withholding, treaty benefits and manufactured-dividend treatment cannot be assumed from issuer-country information alone. cannot be mitigated.
