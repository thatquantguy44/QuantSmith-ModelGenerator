## Best research-to-production choices

1. **06 Collateral stale-mark quarantine:** start with unit/convention/time fixtures; a conservative exception monitor has clearer acceptance than unobserved trading alpha. Independent pricing lineage is the main dependency.
2. **08 Calendar bridge planner:** public official service schedules support a deterministic first prototype; private balances are needed only for economic validation.
3. **09 Benchmark outage monitor:** public publication/version capture can begin immediately; hypothetical outage tests prove software resilience, not financial return.
4. **18 Global covariance-break controller:** start with synthetic asynchronous sessions and a simple shrinkage/no-trade control; licensed total returns and costs are required before investment conclusions.
5. **11 Japan buyback completion:** public event definitions and a transparent probability target; delistings, original filings and execution prices are material gates.

**High-risk research bet:** 16 corridor/jump risk budgeting has substantial method value but expensive data and weak extreme-tail identification. **Defer 20 water/crop hedge** until a stable regional-to-tradable basis is shown; a useful physical scarcity index need not produce a tradable strategy.
