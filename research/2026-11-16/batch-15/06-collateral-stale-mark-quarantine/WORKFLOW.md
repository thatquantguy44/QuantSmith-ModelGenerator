# Research workflow — Collateral Stale-Mark Quarantine and Conservative Valuation

1. **Data => rights/time audit.** Ingest collateral instrument x mark source x quote/receive event through proposed `collateral_marks`; save exact release bytes privately where rights permit and only public-safe manifests here. Check Gate each mark at ingestion before its use in a financing solve; reference marks must be received earlier than the current solve. Labels are adjudications collected later and assigned only to future model training windows. Unknown data rights or availability yields BLOCKED.
2. **Hypothesis => pre-registration.** Freeze A cross-source temporal-consistency gate reduces unsecured-value underestimation by at least 30% versus last-price carry-forward at an operational false-quarantine rate below 1%. Define native-horizon targets and independent event groups; lock costs, limits and partition dates before seeing holdout outcomes.
3. **Baseline => reproducible control.** Implement Use latest received price within a fixed one-day age limit; otherwise last valid mark with static buffer. Verify Inject a 100x currency/unit error, stale timestamp, ex-coupon drop and two nominally independent marks with identical upstream provenance; detect unit/staleness defects while preserving valid convention changes. Keep equal information and economic constraints across methods.
4. **Candidate => interpretable action.** Build source age, price convention residual, lineage overlap and conservative interval; fit/solve Robust cross-source median and asset-specific age/interval rule. Return mark status, safe monitoring valuation, lineage warning and escalation reason plus a feasibility/time certificate. Advanced research `State-space price filtering with conformal lower valuation bounds and selective quarantine` stays optional.
5. **Validation => objective verdict.** Report value shortfall, interval coverage, false positives, stale detection delay, desk override rate and review hours. GO if underestimation falls >=30%, clean-mark false quarantine <1%, and lower-bound coverage >=99% in stress replay; reject if benefit comes only from excessive haircuts or review burden exceeds 0.5 FTE per 10k instruments. Double execution costs and halve capacity; include zero-benefit and delayed-launch ROI scenarios.
6. **Review => private shadow.** Domain reviewer challenges Independent sources can share the same vendor lineage. Corporate actions and currency factors can look like outliers; later corrections create hindsight labels. Complete rights and capacity evidence before any prospective shadow run. Human review is required; runtime deployment and trading need separate authority.

All transitions are future gates, currently BLOCKED. A failed experiment is retained with source/config/code hashes; reruns cannot overwrite an adverse outcome or silently relax a threshold. Generated reports label FACT/HYPOTHESIS/ASSUMPTION/CALCULATION/UNVERIFIED and preserve the original baseline alongside candidate output.
