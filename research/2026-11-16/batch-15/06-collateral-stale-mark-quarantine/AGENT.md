# Research-agent contract — Collateral Stale-Mark Quarantine and Conservative Valuation

**Authority:** analyze US and euro-area secured financing collateral using public, rights-approved or synthetic inputs; propose experiments and auditable recommendations. This contract does not instantiate an agent executor. Do not trade, message counterparties, repricing-contracts, certify legal rights, grant data access, deploy or merge.

**Inputs:** Raw vendor price/event/receive timestamps, currency, clean/dirty convention, coupon accrual, corporate actions, independent quote source and later adjudicated corrections. Public rates and eligible-asset terms support synthetic scenarios, not intraday bond valuation. Require `collateral instrument x mark source x quote/receive event` plus source/version/hash, unit/currency and the common time envelope. Public run mode rejects permissioned adapters and vendor extracts whose redistribution has not been approved.

**Decision scope:** Quarantine a suspect mark or assign a conservative valuation interval, escalating exceptions rather than automatically altering contractual marks. Build source age, price convention residual, lineage overlap and conservative interval, compare baseline `Use latest received price within a fixed one-day age limit; otherwise last valid mark with static buffer.` with `Robust cross-source median and asset-specific age/interval rule`, and return mark status, safe monitoring valuation, lineage warning and escalation reason. Preserve failed fits and HOLD/BLOCKED actions.

**Evidence gates:** distinguish FACT (a linked source supports precisely the stated claim), HYPOTHESIS (the new research question), ASSUMPTION (cost/capacity/timing), CALCULATION (explicit inputs/formula) and UNVERIFIED. A paper or matching citation span cannot establish a new empirical effect. No statement of outperformance is permitted before [EVALS](EVALS.md) and QMG-20261116-06-AC-01 pass.

**Hard controls:** Gate each mark at ingestion before its use in a financing solve; reference marks must be received earlier than the current solve. Labels are adjudications collected later and assigned only to future model training windows. Target p99 <=100ms per 1,000-mark batch excluding upstream network; missing currency/convention hard-fails. Keep original marks immutable. Inject a 100x currency/unit error, stale timestamp, ex-coupon drop and two nominally independent marks with identical upstream provenance; detect unit/staleness defects while preserving valid convention changes.

**Escalation:** missing rights, contradictory terms, unknown availability or infeasibility => BLOCKED with affected IDs and minimal reproducible evidence. Economics review uses the README ROI formula; never fill missing prices with synthetic values without explicit synthetic labeling. Human domain reviewer assesses Independent sources can share the same vendor lineage. Corporate actions and currency factors can look like outliers; later corrections create hindsight labels.
