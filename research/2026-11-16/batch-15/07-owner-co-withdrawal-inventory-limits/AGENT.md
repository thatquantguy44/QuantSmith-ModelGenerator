# Research-agent contract — Owner Co-Withdrawal Limits for Lendable Inventory

**Authority:** analyze US and European agency lending mandates using public, rights-approved or synthetic inputs; propose experiments and auditable recommendations. This contract does not instantiate an agent executor. Do not trade, message counterparties, repricing-contracts, certify legal rights, grant data access, deploy or merge.

**Inputs:** Permissioned daily available/withdrawn quantities by owner and security, mandate inception/termination, owner-group lineage, public N-PORT filings and known rebalance calendars. Public monthly/quarterly holdings are lagged aggregate context only. Require `owner x security x dated available-inventory snapshot` plus source/version/hash, unit/currency and the common time envelope. Public run mode rejects permissioned adapters and vendor extracts whose redistribution has not been approved.

**Decision scope:** Cap loans supported by correlated sources and keep replacement options against simultaneous owner withdrawals. Build common withdrawal factor, owner lineage groups and replacement tail scenarios, compare baseline `Static 10% owner concentration cap with independent withdrawal probabilities.` with `Hierarchical common-factor withdrawal model and CVaR allocation`, and return source concentration limits and joint-withdrawal stress certificate. Preserve failed fits and HOLD/BLOCKED actions.

**Evidence gates:** distinguish FACT (a linked source supports precisely the stated claim), HYPOTHESIS (the new research question), ASSUMPTION (cost/capacity/timing), CALCULATION (explicit inputs/formula) and UNVERIFIED. A paper or matching citation span cannot establish a new empirical effect. No statement of outperformance is permitted before [EVALS](EVALS.md) and QMG-20261116-07-AC-01 pass.

**Hard controls:** Set next-day inventory limits after local close using confirmed availability received by cutoff; public fund holdings enter at filing acceptance, not portfolio as-of date. Never condition on the owner's future sale or recall notice. No raw owner identity or positions in public artifacts; a private run must use pseudonymous IDs and lineage access controls. Duplicate an owner under two IDs: effective diversification must not improve; simulate perfect co-withdrawal and verify the model does not report independent-source protection.

**Escalation:** missing rights, contradictory terms, unknown availability or infeasibility => BLOCKED with affected IDs and minimal reproducible evidence. Economics review uses the README ROI formula; never fill missing prices with synthetic values without explicit synthetic labeling. Human domain reviewer assesses Mandate closure is not an iid recall; inactive and terminated owners must remain in the sample. Co-movement can be driven by security demand rather than shared owner behavior.
