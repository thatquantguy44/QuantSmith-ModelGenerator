# Shared agent workflow
1. Source agent produces release-vintage and license manifest; do not download restricted data. 2. Research agent reads each SPEC and freezes H1, baseline, metrics and gates. 3. Implementation agent builds synthetic fixtures, then authorized adapters and deterministic computations in a separate PR. 4. Independent validation agent compares same feasible opportunities, tests negatives, computes uncertainty, checks economics and writes negative findings. 5. Reviewer signs off on rights, constraints and empirical status. 6. Human approval required before shadow or production. Shared proposed Python modules: temporal/vintage, entity/units, source registry, economic costs, solver diagnostics, paired evaluation, claim ledger. Agent prompts are not executable infrastructure. Never place trades or publish private records.
