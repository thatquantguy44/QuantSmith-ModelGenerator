# Research skill — Securities-Lending Circular Flow Surveillance via Temporal Graphs
## Trigger
When a quant team asks to **Escalate suspicious short-lived circular borrow/return patterns for compliance review without inferring wrongdoing from volume alone.** in Multi-agent securities loans and collateral transfers; US/EU.
## Required inputs
Legal scope, decision timestamp, synthetic securities loan transfer edge × security × event timestamp, fields (Synthetic multi-party loan/return event graph, matched collateral movement, legitimate transfer controls, anonymized case annotations if permitted.), approved source license, trade/operating costs and untouched outcome window.
## Steps
1. Inspect SPEC H1/H0 and Batch-14 cross-book identity reconciler targets *record matching*; this tests suspicious multi-party circular behavior at a fixed review budget.
2. Cite official source links, separate publication from effective date; follow Create graph only from recorded transfers visible before alert time; disallow knowledge of subsequent investigation outcomes in features.
3. Build a synthetic point-in-time fixture with missing, late and contradictory events.
4. Reproduce baseline `Two-party net-quantity turnaround rules`, compare to do-nothing under matched constraints.
5. Prototype `Temporal graph motif detection with exact deterministic event identity` and retain `Weakly supervised dynamic graph anomaly ranking with human-in-loop conformal calibration` only if ablation justifies.
6. Evaluate `precision at K, seeded motif recall, legitimate-flow false-alerts, explanation fidelity`; stress False accusations, privileged customer data, and severe sample-selection bias in investigated cases.
7. Apply hard stop: No precision@K gain against pairwise rules under benign high-volume churn fixtures.
8. Report cost/capacity and explicit invented ROI sensitivity separately from verified empirical effects.
9. Update HANDOFF with evidence links and red flags; no live integration without human signoff.
## Output contract
Proposed `source_ledger.json`, `pit_manifest.json`, `baseline_metrics.json`, `candidate_metrics.json`, `risk_report.md`, `review_record.md` (not created by this doc PR).
## Failure behavior
