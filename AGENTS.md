# QuantSmith-ModelGenerator: Agent instructions

**Purpose:** Public, reproducible hypothesis design for financing and quantitative market structure.
**Do not:** commit confidential employer data, client information, proprietary quotes, credentials, vendor data, nonpublic information, or inferred private positions.
**Authority:** Agents draft research plans, point-in-time contracts, synthetic fixture designs and evaluations; they never place trades, approve contracts, waive compliance gates, invent returns, or auto-merge PRs.
**Artifacts:** Each dated batch contains one leaderboard and 15 idea folders, each with research and AI Markdown contracts.
**Checks:** Verify official source portal vs specific dataset access; prevent lookahead, leakage, data licensing violations and impossible baselines; label everything proposal until independently tested.
**Publishing:** Branch `research/YYYY-MM-DD-batch-NN`, one draft PR per batch, verify file count and links, no automatic merge. Report negative evidence and missing tools openly.
